# Community code of conduct

Be respectful, constructive and welcoming. Discuss technical choices with evidence. Harassment, discrimination, threats, doxxing and publishing another person's private information are not acceptable.

Maintainers may edit or remove harmful content and restrict participation proportionately. Apply these expectations consistently in issues, pull requests and project-associated discussions.

For moderation help, open a brief non-sensitive moderation request without repeating abusive or private material. Ask the maintainer for a private route before sharing sensitive details. Security vulnerabilities use the separate [security reporting process](SECURITY.md).
